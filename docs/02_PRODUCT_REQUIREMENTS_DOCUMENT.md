# Product Requirements Document

## Summary
ITA is an AI-assisted EdTech platform combining structured lessons, illustrated handbooks, interactive chart exercises, AI coaching, journaling, assessments, and certification.

## Core Product Areas
1. Learn
2. Practice
3. Trading Lab
4. AI Coach
5. Journal
6. Progress
7. Certifications
8. Knowledge Hub
9. Community
10. Admin CMS

## MVP
- Authentication
- Student dashboard
- Learning paths
- Mission pages
- Quizzes
- Progress tracking
- English/Arabic switch
- AI character-assisted explanations
- Journal
- Basic Trading Lab
- Admin content management

## Safety
- Clear risk disclosures
- No personalized financial advice
- No guaranteed returns
- Risk module required before execution simulations
