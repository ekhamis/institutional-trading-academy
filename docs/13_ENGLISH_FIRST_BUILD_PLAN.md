# English-First Build Plan

## Current release - v0.2
- Dual-language repository structure
- English content as the master source
- Arabic placeholders and localization status tracking
- First ten fully authored foundation missions
- First illustrated English handbook PDF and DOCX

## English completion gates
A mission is considered concluded only when it has:
1. Approved learning objective
2. Fact-checked core explanation
3. Original illustration or chart specification
4. Practical exercise
5. Quiz and answer key
6. Evidence classification
7. Official or primary sources
8. Risk and scope review
9. Final editorial pass

## Arabic start condition
Arabic authoring starts after the English foundation volume is content-locked and the glossary is approved.
