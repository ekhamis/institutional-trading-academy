# UI/UX System

## Direction
Professional, calm, chart-first, uncluttered.

## References
Finelo for onboarding, Duolingo for progression, TradingView for charts, Bloomberg for hierarchy, Apple for clarity.

## Core Screens
Onboarding, dashboard, learning path, mission, Trading Lab, AI Coach, journal, skill tree, certifications, Knowledge Hub, Admin CMS.

## Principles
- One primary action per screen
- Short lessons with optional deep dives
- Persistent progress
- Dark/light mode
- Native Arabic RTL
- Mobile-first
- Accessible contrast and scalable typography
