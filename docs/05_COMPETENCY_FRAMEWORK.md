# Competency Framework

## Levels
1. Awareness
2. Understanding
3. Guided Application
4. Independent Application
5. Consistent Performance
6. Mentoring Capability

## Core Competencies
Financial literacy, market mechanics, chart reading, structure, volume, liquidity, order flow, macro context, planning, risk, execution, journaling, review, ethics.

## Evidence
Quiz, chart annotation, scenario decision, written plan, risk calculation, simulation, reflection, repeated performance.
