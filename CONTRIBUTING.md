# Contributing

## Content workflow
1. Create a branch from `main`.
2. Edit the English canonical mission and structured data together.
3. Add or update illustrations and sources.
4. Run `python scripts/validate_project.py`.
5. Open a pull request using the review checklist.
6. Merge only after educational, risk, source, and visual review.

## English-first localization policy
English remains the source language until the English academy is content-locked. Arabic folders and locale files must remain structurally ready, but Arabic mission authoring is deferred.

## Commit conventions
- `feat(content): add missions 21-30`
- `fix(content): correct order-type explanation`
- `feat(ui): expand dashboard prototype`
- `docs: update curriculum roadmap`
- `chore(release): prepare v0.4.0`
